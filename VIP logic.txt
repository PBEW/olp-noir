VIP Life-cycle Logic
⏱️ 1. Logic การนับวันหมดอายุยศ VIP (Expiration Logic)
1. การคำนวณวันหมดอายุ (Expiry Calculation):
   * รายเดือน (1 Month): Expiry Date = Current Date + 30 Days (หรือ 31 วันตามเดือน)
   * เงื่อนไขพิเศษปลายเดือนมกราคม (January-February Edge Case): หากวันที่ซื้อ หรือวันที่ต่ออายุ ตรงกับวันที่ 29, 30 หรือ 31 มกราคม ให้กำหนดวันหมดอายุเป็นวันที่ 28 กุมภาพันธ์ เสมอ (เพื่อไม่ให้วันหมดอายุข้ามไปล้นในเดือนมีนาคม)
   * (หมายเหตุ: หากปีนั้นเป็นปีที่เดือนกุมภาพันธ์มี 29 วัน สามารถปรับให้หมดวันที่ 29 กุมภาพันธ์ได้ตามความเหมาะสมของปฏิทิน)
   * รายปี (1 Year): Expiry Date = Current Date + 365 Days
2. การสะสมเวลาเมื่อซื้อซ้ำ/ต่ออายุ (Stacking Logic):
   * หากลูกค้า มี VIP ยศเดิมอยู่แล้ว และทำการซื้อต่ออายุ ก่อนวันหมดอายุ:
      * New Expiry Date = Old Expiry Date + 30 Days (บวกเพิ่มจากวันหมดอายุเดิม ไม่ใช่วันที่กดซื้อ)
   * หากลูกค้า VIP หมดอายุไปแล้ว แล้วกดซื้อใหม่:
      * New Expiry Date = Current Date + 30 Days
3. การอัปเกรดยศ (Upgrade Logic):
   * หากลูกค้าเปลี่ยนยศจาก VIP Lace ➔ VIP Desire ให้ปรับยศทันที และเริ่มนับ 30 วันใหม่นับจากวันที่อัปเกรด
4. Auto-Revoke Cron Job (ระบบปลด ยศอัตโนมัติ):
   * ให้ตั้ง Task Loop/Cron Job ตรวจสอบเวลาทุกวัน เวลา 00:00 น.
   * หาก Current Date > Expiry Date:
      * ถอด Role VIP ออกจากตัวลูกค้าใน Discord
      * ปรับสถานะสิทธิ์ VIP ใน Database เป็น EXPIRED
      * ส่ง DM แจ้งเตือนลูกค้าว่า "สิทธิ์ VIP ของคุณหมดอายุแล้ว"
🔄 2. Logic การรีเซ็ตโวน่า/สิทธิ์ฟรีประจำเดือน (Monthly Quota Reset Logic)
สิทธิ์ใช้งานฟรี (เช่น ห้อง VVIP ฟรี, ถ่ายภาพฟรี, Short date ฟรี) ห้ามสะสมข้ามเดือน โดยมี Logic การนับดังนี้:
1. วันรีเซ็ตโควต้า (Reset Trigger):
   * ให้รีเซ็ตโควต้าทุกๆ 30 วันนับจากวันที่ซื้อ (Individual Cycle) หรือ รีเซ็ตพร้อมกัน ทุกวันที่ 1 ของเดือน เวลา 00:00 น. (Monthly Fixed Cycle — แนะนำแบบนี้เพื่อให้จัดการง่าย)
2. การบันทึกการใช้สิทธิ์ (Usage Tracking):
   * สร้าง Table ใน Database เก็บโควต้าที่ใช้ไปแล้วในรอบเดือนนั้นๆ เช่น:
   * JSON
{
  "user_id": 123456789,
  "vip_tier": "VIP_DESIRE",
  "cycle_month": "2026-08",
  "vvip_used": 1,        // จากสิทธิ์ฟรี 2 ครั้ง
  "photo_used": 0,       // จากสิทธิ์ฟรี 1 ครั้ง
  "short_date_used": 2   // จากสิทธิ์ฟรี 2 ครั้ง (ครบแล้ว)
}
   *    * 3. Validation Logic (ตอนแอดมินคีย์เปิดบิล):
   * เมื่อแอดมินคีย์บริการที่มีสิทธิ์ฟรี ให้ระบบเช็ค:
      * IF (quota_used < max_quota) ➔ คิดราคา 0 บาท แล้วบวกค่า quota_used + 1
      * ELSE ➔ คิดราคาปกติ/ราคาส่วนลด VIP ตามตาราง
🎁 3. Logic การคำนวณ Free Upgrade (สะสมครบ 12 เดือน)
อ้างอิงจากตารางสิทธิประโยชน์:
* สะสม VIP Lace ครบ 12 เดือน:
   * เช็คใน Database หาก Lace_Months_Count >= 12 ➔ แจ้งเตือนแอดมินให้อนุมัติปรับยศเป็น VIP Desire ฟรี 1 เดือน
* สะสม VIP Desire ครบ 12 เดือน:
   * เช็คใน Database หาก Desire_Months_Count >= 12 ➔ แจ้งเตือนแอดมินให้อนุมัติปรับยศเป็น VIP Obsession ฟรี 1 เดือน
