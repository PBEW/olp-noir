==============================================
 OLP-Noir Discord Bot — สรุปฟีเจอร์ทั้งหมด
 (PR #1 – #15 · merge เข้า main แล้ว)
==============================================

[1] บิลและการขาย (รีเซปชั่น)
- เปิดบิลผ่านแผงเมนู: เลือกลูกค้า / พนักงาน / บริการ / ห้อง แล้วกรอกเวลา
- 1 บิลเลือกลูกค้าได้สูงสุด 10 คน (แยกบิลคนละใบ ราคาและสิทธิ์ VIP ของใครของมัน)
- เลือกพนักงานได้หลายคน (คนแรกเป็นคนกดรับงาน)
- เลือกได้เฉพาะพนักงานที่กดเข้างานวันนี้แล้ว
- ก่อนยืนยันแสดง: รายรับ (In) / จ่ายพนักงาน (Out) / ร้านได้สุทธิ
- พนักงานกดรับหรือปฏิเสธงานทาง DM แล้วลูกค้าได้ QR ชำระเงินทาง DM
- ต่อเวลา (EXTEND) ใช้ทีมพนักงานชุดเดิม
- ยกเลิกบิล: คืนสิทธิ์ฟรี VIP และลบแถวใน Google Sheets อัตโนมัติ
- Role รีเซปชั่น (แยกจากแอดมิน): รับ Ticket, ตรวจสลิป, ดูสลิปค้าง, ดูรายการส่ง DM ไม่สำเร็จ

[2] ราคาและส่วนแบ่ง
- ส่วนพนักงานเป็นบาทตายตัวรายบริการ ตามตารางร้าน
    Private 109 / 49        VVIP 169 / 79        Private+ERP 199 / 99
    ERP 99 / 49             ต่อเวลา 99 / 49      ที่ปรึกษา 99 / 49
    ถ่ายภาพ 79 / 39         Drink Shot 50 / 50   Tarot 199 / 149
    Special Event 59 / 59   Short date 99 / 49
- บริการที่ไม่ได้ตั้งส่วนพนักงาน: คิดตาม % (ค่าเริ่มต้น หรือตั้งรายคน)
- บิลที่มีพนักงานหลายคน: "หารเท่ากัน" (ค่าเริ่มต้น) หรือ "ได้เต็มทุกคน"
- ลูกค้าใช้สิทธิ์ฟรี VIP: ร้านจ่ายส่วนพนักงานแทน พนักงานยังได้เต็ม

[3] VIP
- ลูกค้าซื้อเองได้ (Lace / Desire / Obsession) และใช้โค้ดส่วนลดได้
- ลูกค้าเลือกพนักงานที่แนะนำ → พนักงานได้ค่าคอม 20% (ปรับได้)
- คิดราคา VIP และโควตาฟรีรายเดือนอัตโนมัติ

[4] โดเนท
- ลูกค้าโดเนทเอง เลือกให้ร้านหรือให้โฮสต์
- แอดมินตรวจสลิป → ประกาศ + ลง Sheets + อันดับ (leaderboard)

[5] ลงเวลาพนักงาน
- กดเข้างานครั้งเดียว ไม่ต้องกดออกงาน บอทตัดให้ตอน 01:00
- กดผิดได้ → ปุ่ม "ยกเลิกเข้างาน"
- ปุ่ม "คนมาทำงานวันนี้" (พนักงานและรีเซปชั่นดูได้)
- /daily_checkin = เช็กอินรายวันทั่วไป (ไม่เกี่ยวกับการทำงาน)

[6] เมนูพนักงาน (/panel_staff)
- เข้างาน / ยกเลิกเข้างาน / ชั่วโมงของฉัน
- รายได้รอบนี้ (ส่วนแบ่ง + โดเนท + ค่าคอม VIP)
- งานของฉัน

[7] Google Sheets และตัดรอบ
- 1 แท็บต่อเดือน (บัญชี_YYYY-MM) ตัดรอบรายสัปดาห์ (คอลัมน์ "รอบ")
- บิล โดเนท และขาย VIP อยู่ในตารางเดียวกัน
- กล่องสรุปด้านขวา: ยอดรวม / จ่ายพนักงาน / รายได้ร้าน / ยอดโอนพนักงานแยกตามรอบ
- พนักงานร่วมได้แถวของตัวเอง (เช่น 12-2)
- ลงย้อนหลังให้รายการที่ตกหล่นอัตโนมัติ
- ปุ่มจัดรูปแบบชีตใหม่ + แท็บ Attendance
- ตัดรอบแล้วส่งสรุปยอด / ชั่วโมงทำงาน / ยอดโอนรายคน ให้แอดมิน

[8] ตั้งค่าร้านผ่าน Discord (/panel_admin → ตั้งค่าร้าน)
- ห้อง, บริการ + ราคา / ส่วนพนักงาน, แพ็กเกจ VIP + ค่าคอม
- % ส่วนแบ่ง, โค้ดส่วนลด, Role, ห้องแจ้งเตือนแยกหัวข้อ
- ทุกการแก้ไขบันทึกลงห้อง log

[9] ระบบอื่น ๆ
- แจ้งเตือนก่อนเริ่มงานและก่อนหมดเวลา (พนักงาน + ลูกค้า)
- ส่งรีวิวหลังจบงาน
- แจ้งเตือนเมื่อบอท restart
- โพสต์แผงใหม่แล้วลบแผงเก่าอัตโนมัติ
- config.example.json = แม่แบบ / config.json จริงอยู่เฉพาะในเครื่อง (ไม่ขึ้น GitHub)

[ยังไม่ได้ทำ / รอตัดสินใจ]
- บันทึกค่าใช้จ่ายร้าน (เช่น ค่าแรง Reception/Security วันละ 100)
- แบ่งส่วนพนักงานหลายคนแบบไม่เท่ากัน (เช่น 60/40)
- เช็กตัวเลข Tarot (199 กับ 59+149) ว่าส่วนพนักงาน 149 ถูกไหม
