📑 System Requirement & Concept Brief: OLP-Noir Bot
Project Name: OLP-Noir (Discord Automation Bot)
Target Platform: Discord (discord.py / discord.js)
Core Concept: บอทบริหารจัดการร้าน Hosting / Cafe แบบกึ่งอัตโนมัติ ใช้งานง่าย ลดภาระแอดมิน บันทึกบัญชีผ่าน Google Sheets อัตโนมัติ และมีระบบคัดกรองรีวิว
1) ส่วนงานรีเซปชั่น / แอดมินคีย์เปิดบิล (Billing & Operations)
ส่วนนี้เป็นศูนย์กลางการทำงานของแอดมินและพนักงานต้อนรับ เพื่อจัดคิว คำนวณราคา เก็บเงิน และลงบัญชี
Step 1: แอดมินเปิดบิล (Open Bill Panel)
แอดมินกดปุ่ม 🧾 เปิดบิลใหม่ หน้าแผงควบคุม (Reception Control Panel)
เลือกข้อมูลผ่าน UI ในขั้นตอนเดียว:
ลูกค้า (User Select)
พนักงาน/โฮสต์ (User Select)
บริการที่ใช้ (Select Menu - เลือกได้มากกว่า 1 รายการ)
ห้องที่ใช้งาน (Select Menu - บังคับเลือกเฉพาะบริการห้อง VIP,VVIP,ดูดวง)
กรอก เวลาเริ่มงาน และ หมายเหตุ 
Dynamic Pricing: บอทคำนวณราคารวมและเวลาจบงานให้อัตโนมัติ โดยตรวจเช็ค Role ของลูกค้า หากมี Role VIP ระบบจะปรับเป็นราคา VIP โดยอัตโนมัติ
Step 2: พนักงานรับงาน & ลูกค้าชำระเงิน (Staff Confirm & Payment)
บอทส่งแจ้งเตือนงานไปที่ DM ของพนักงาน เพื่อให้กด ✅ รับงาน
เมื่อพนักงานรับงาน บอทส่งสรุปยอดชำระเงินพร้อม QR Code ไปที่ DM ของลูกค้าทันที
Slip Verification: ลูกค้าส่งภาพสลิปโอนเงินเข้า DM บอท -> กดปุ่มยืนยัน -> สลิปถูกส่งไปที่ห้องแอดมิน (ADMIN_CHANNEL) -> แอดมินกด ✅ ยืนยันสลิปถูกต้อง -> บอทแจ้งลูกค้าว่าชำระเงินสำเร็จ
Step 3: ระบบแจ้งเตือนเวลางาน (Auto Time Notification Loop)
บอททำ Task Loop ตรวจสอบเวลาทุกๆ 30–40 วินาที
ก่อนเริ่มงาน 5 นาที: ส่ง DM เตือนพนักงาน (เตรียมตัว) และลูกค้า (เตรียมเข้างาน)
ก่อนจบงาน 5 นาที: ส่ง DM เตือนเวลาใกล้หมด (เตรียมปิดงานหรือขอต่อเวลา)
Step 4: บันทึกบัญชีอัตโนมัติ & ตัดรอบ (Google Sheets Integration)
Real-time Recording: เมื่อบิลขึ้นสถานะชำระเงินแล้ว (PAID) บอทจะบันทึกข้อมูลลง Google Sheets ทันที
Split Revenue (In/Out): คำนวณรายรับรวม (In), ส่วนแบ่งพนักงาน (Out), และรายได้เข้าร้าน (Shop Share) ตามเปอร์เซ็นต์ที่กำหนดไว้ใน Config แยกตามรายชื่อพนักงาน
Weekly Automatic Cut-off: ทุกวันเสาร์ เวลา 08:00 น. (เวลาไทย) บอทจะสร้าง Sheet (Tab) ใหม่ขึ้นมาอัตโนมัติ (เช่น Cycle_YYYY-MM-DD) พร้อมขึ้นโครงสร้างสูตรคำนวณใหม่ และส่งสรุปยอดรวมของสัปดาห์เก่าเข้าห้องแอดมิน
Step 5: การต่อเวลา (Extend Session):
หากลูกค้าขอต่อเวลาระหว่างทำกิจกรรม ให้มีระบบเปิดบิลประเภท EXTEND ได้
บอทจะทำการ ขยายเวลาจบงาน (End Time) ของ Job ID เดิมออกไปโดยอัตโนมัติ เพื่อให้ระบบแจ้งเตือนก่อนจบงานคำนวณเวลาใหม่ถูกต้อง
Step 6: การยกเลิกบิล (Bill Cancellation): 
เพิ่มปุ่ม ❌ ยกเลิกบิล ในหน้าตรวจสอบสลิปของแอดมิน
หากกดยกเลิก บอทจะเปลี่ยนสถานะ Job เป็น CANCELLED และ ไม่นำยอดเงินไปบันทึกใน Google Sheets
2) ส่วนลูกค้าเปิด Ticket สอบถามข้อมูล (Customer Support Ticket)
ส่วนสำหรับให้บริการตอบคำถามและช่วยเหลือลูกค้าแบบ 1-on-1 โดยไม่เข้าสู่ระบบคิวบริการหรือการเปิดบิล
Customer Opening: ลูกค้ากดปุ่ม 💬 สอบถามเจ้าหน้าที่ ที่หน้า Request Panel
Admin Notification: บอทส่งข้อความแจ้งเตือน Ticket ใหม่ไปที่ห้องแอดมิน (ADMIN_CHANNEL) พร้อมระบุชื่อลูกค้า
Live Chat Bridge (DM Bridge):
แอดมินกดปุ่ม ✅ รับเรื่อง (Chat)
บอทจะทำหน้าที่เป็นสะพานส่งข้อความ (DM Bridge) ระหว่างลูกค้าและแอดมินโดยตรง ทำให้สามารถพิมพ์โต้ตอบกันผ่าน DM ของบอทได้ทันที
Exclusion Note: รายการสอบถามข้อมูลนี้ จะไม่ถูกนำไปคำนวณเงินลง Google Sheets และ ไม่มีระบบส่งแบบประเมินรีวิว เมื่อจบการสนทนา
Ticket Timeout/Close: หากแอดมินหรือลูกค้าไม่มีการพิมพ์โต้ตอบกันในระบบ Ticket เกิน 10 นาที ให้บอทส่งข้อความปิด Ticket อัตโนมัติ เพื่อไม่ให้เปิดห้องแชทค้างไว้ 
3) ส่วนลูกค้าซื้อ VIP / ต่ออายุ VIP / ตรวจสอบสิทธิ์ VIP (VIP Self-Service)
ระบบอัตโนมัติให้ลูกค้าจัดการสิทธิ์ VIP ได้ด้วยตนเองผ่าน DM
Selection & Checkout:
ลูกค้ากดปุ่ม 💎 ซื้อ VIP/ต่ออายุ ที่หน้า Request Panel
เลือกแพ็กเกจที่ต้องการผ่าน Dropdown (เช่น VIP Lace รายเดือน/รายปี, VIP Desire รายเดือน/รายปี)
กรอกโค้ดส่วนลด (ถ้ามี) ใน Pop-up Modal
Payment Flow:
บอทส่งรายละเอียดแพ็กเกจ ยอดชำระเงิน และ QR Code ไปให้ลูกค้าใน DM
ลูกค้าส่งภาพสลิปใน DM -> ผ่านกระบวนการตรวจสลิปโดยแอดมิน (Slip Verification)
Auto Role & Eligibility Check:
เมื่อแอดมิน ยืนยันสลิปสำเร็จ บอทจะทำการยศ/บทบาท (Role VIP) ให้ลูกค้าในเซิร์ฟเวอร์โดยอัตโนมัติ
เมื่อลูกค้ามาใช้บริการอื่นๆ ในอนาคต ระบบคีย์เปิดบิล (ในข้อ 1) จะตรวจสอบ Role VIP นี้เพื่อคำนวณราคาส่วนลด VIP ให้อัตโนมัติ
4) ส่วนรีวิวหลังจบบริการ (Review & Approval System)
ระบบประเมินความพึงพอใจหลังจบงาน (ยกเว้นบริการสอบถามข้อมูล Ticket จะไม่มีส่วนนี้)
Trigger & Limit:
เมื่อถึงเวลาจบงานของบริการนั้นๆ บอทจะส่ง DM ขอบคุณลูกค้า พร้อมแนบปุ่ม ✍️ เขียนรีวิวเลย
จำกัดสิทธิ์ให้กดเขียนรีวิวได้ภายใน 24 ชั่วโมง หลังจบงานเท่านั้น
Review UI Submission:
ลูกค้าเลือกคะแนนผ่าน Dropdown 2 ส่วน:
คะแนนความประทับใจ (⭐ 1-5)
คะแนนความแซ่บ (🔥 1-5)
กรอกข้อความรีวิวผ่าน Pop-up Modal
Admin Approval:
ข้อมูลรีวิวจะถูกส่งไปที่ห้องแอดมินเพื่อรอการตรวจสอบ
แอดมินกด ✅ อนุมัติลงรีวิว หรือ ❌ ปฏิเสธ
Public Review Embed (หน้าช่องรีวิว):
เมื่อแอดมินอนุมัติ รีวิวจะถูกโพสต์ลงช่อง REVIEW_CHANNEL ในรูปแบบ Discord Embed สีชมพูพรีเมียม
Layout การแสดงผล:
Title: 💖 รีวิวจากลูกค้า
Thumbnail: รูป Avatar ของพนักงานที่ถูกรีวิว
Fields:
คะแนน: แสดงดาวตามจำนวนที่เลือก (⭐⭐⭐⭐⭐)
ความแซ่บ: แสดงไฟตามจำนวนที่เลือก (🔥🔥🔥🔥🔥)
ความประทับใจ: แสดงข้อความรีวิวภายใน Code Block สีดำ (```)
พนักงาน: Mention พนักงาน (@Staff)
บริการที่ใช้: แสดงชื่อบริการที่ลูกค้าใช้
Footer: โดยคุณ: [Display Name ของลูกค้า]
One-Time Review Limit: 
บิล 1 ใบ (1 Job ID) สามารถ ส่งรีวิวได้เพียงครั้งเดียวเท่านั้น (ป้องกันลูกค้ากดรีวิวซ้ำ) 
Staff Deletion Handling: 
หากพนักงานคนนั้นลาออก หรือไม่มี Discord User อยู่ในเซิร์ฟเวอร์แล้ว เมื่ออนุมัติรีวิว ให้บอทแสดงเป็นชื่อข้อความธรรมดาแทนการ Mention @Staff เพื่อไม่ให้ Embed รีวิวขึ้นข้อความ Error
