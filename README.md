# OLP-Noir · Discord Automation Bot

บอทบริหารร้าน Hosting / Cafe ตามสเปกในไฟล์ `รายละเอียด.txt`
เขียนด้วย **discord.py 2.x** + **SQLite** + **Google Sheets (ไม่บังคับ)**

---

## 1. ติดตั้ง

```bash
python -m venv .venv
```

```bash
.venv\Scripts\pip install -r requirements.txt
```

คัดลอกไฟล์ตั้งค่า แล้วแก้ค่าให้ตรงกับเซิร์ฟเวอร์ของคุณ:

```bash
copy .env.example .env
```

- `.env` → ใส่ `DISCORD_TOKEN`
- `config.json` → ถ้ายังไม่มี บอทจะคัดลอกจาก `config.example.json` ให้อัตโนมัติตอนรันครั้งแรก

## 2. ตั้งค่าใน Discord Developer Portal

ที่หน้า **Bot** ต้องเปิด Privileged Intents ทั้ง 2 อัน:

- ✅ **Server Members Intent** (ใช้ตรวจระดับ VIP และให้ Role)
- ✅ **Message Content Intent** (ใช้กับสะพานแชท DM และการรับสลิป)

เชิญบอทเข้าเซิร์ฟเวอร์ด้วยสิทธิ์: `Manage Roles`, `Send Messages`, `Embed Links`, `Attach Files`, `Read Message History`
และ **ลาก Role ของบอทให้อยู่เหนือ Role VIP ทั้ง 3 ระดับ** ไม่งั้นบอทจะให้/ถอด Role ไม่ได้

## 3. แก้ `config.json`

| คีย์ | ความหมาย |
|---|---|
| `guild_id` | ID เซิร์ฟเวอร์ (ใส่แล้ว slash command จะขึ้นทันที) |
| `channels.admin` | ห้องแอดมิน — รับสลิป, ตั๋วสอบถาม, รีวิวรอตรวจ, คำขออัปเกรดฟรี, สรุปตัดรอบ |
| `channels.review` | ห้องโพสต์รีวิวสาธารณะ |
| `roles.staff` | Role พนักงาน — กดปุ่มเข้างาน/ออกงานได้ (แอดมินกดได้เสมอ) |
| `roles.on_duty` | Role "On Duty" — บอทให้ตอนเข้างานและถอดตอนออกงาน (ใส่ 0 = ไม่ใช้) |
| `attendance` | `warn_hours` เตือนทาง DM เมื่อเข้างานนานเกินกี่ชั่วโมง, `auto_close_hours` ปิดกะอัตโนมัติ |
| `roles.admin` | Role แอดมิน (คนที่กดปุ่มยืนยันสลิป/อนุมัติรีวิว/อนุมัติอัปเกรดได้) |
| `vip_tiers` | ระดับ VIP 3 ระดับ (`lace` → `desire` → `obsession`) พร้อม `role_id` ของแต่ละระดับ — **ต้องใส่ `role_id` ให้ครบทั้ง 3** |
| `vip_packages` | แพ็กเกจที่ซื้อได้จริง (Lace/Desire รายเดือน-รายปี) อ้างอิง `tier` จาก `vip_tiers` — **Obsession ซื้อเองไม่ได้** ตั้งใจไม่มีแพ็กเกจให้ซื้อ |
| `services` | บริการ 10 รายการ แต่ละอันมี `pricing.normal/lace/desire/obsession` — เป็นได้ทั้งราคาคงที่ หรือ `{free_per_month, after_price}` (โควต้าฟรี) หรือ `{unlimited: true}` |
| `rooms` | ห้องบริการ 7 ห้อง (ใช้ร่วมกันได้กับทุกบริการที่ `require_room: true` — ไม่ได้ล็อกห้องเฉพาะเจาะจงกับบริการ) |
| `discount_codes` | โค้ดส่วนลด (`percent` หรือ `amount`) — ใช้กับการซื้อ/ต่ออายุ VIP |
| `revenue_share` | เปอร์เซ็นต์ส่วนแบ่งพนักงาน (ตั้งรายคนได้ด้วย Discord ID) |
| `payment` | เลขพร้อมเพย์ + ลิงก์รูป QR ที่จะส่งให้ลูกค้า |
| `cutoff` | วัน/เวลาตัดรอบ (ค่าเริ่มต้น: `weekday: 5` = เสาร์, 08:00 เวลาไทย) |

> `require_room: true` ตั้งไว้ที่ 4 บริการ: เช่าห้อง Private, เช่าห้อง Private VVIP, ห้อง Private + ERP, Tarot/ดูดวง

## ระบบที่มี

### 1) รีเซปชั่น / เปิดบิล
- 🧾 **เปิดบิลใหม่** — เลือกลูกค้า, พนักงาน, บริการ (หลายรายการ), ห้อง ในแผงเดียว แล้วกรอกเวลาเริ่ม + หมายเหตุใน Modal
- คิดราคาและเวลาจบให้อัตโนมัติตาม **ระดับ VIP ปัจจุบันของลูกค้า** (ปกติ/Lace/Desire/Obsession) — ถ้าบริการนั้นมีโควต้าฟรีของระดับนั้น (เช่น ห้อง VVIP ฟรี 2 ครั้ง/เดือนสำหรับ Desire) ระบบจะตัดสิทธิ์ฟรีให้อัตโนมัติ แล้วค่อยคิดราคาปกติเมื่อใช้ครบโควต้าแล้ว
- พนักงานได้ DM พร้อมปุ่ม ✅ รับงาน → ลูกค้าได้ DM สรุปยอด + QR ทันที
- ลูกค้าส่งรูปสลิปใน DM → กด **ยืนยันส่งสลิป** → เข้าห้องแอดมิน → แอดมินกด ✅ ยืนยัน หรือ ❌ ยกเลิกบิล
- ⏱️ **ต่อเวลา** — เปิดบิลประเภท `EXTEND` และขยาย `end_time` ของบิลเดิมให้อัตโนมัติ (การแจ้งเตือนก่อนจบงานคำนวณใหม่)
- ยกเลิกบิล → สถานะ `CANCELLED`, **ไม่บันทึกลง Google Sheets**, และ **คืนสิทธิ์ฟรีที่เคยใช้ไปให้ลูกค้า** (ถ้าเป็นบิลต่อเวลา ระบบจะถอนเวลาที่ต่อออกจากบิลแม่ให้ด้วย)

รูปแบบเวลาที่กรอกได้: `ตอนนี้` · `+15` · `20:30` · `05/09 20:30` · `2026-09-05 20:30`

### 2) Ticket สอบถามข้อมูล
- 💬 ลูกค้ากดปุ่ม → แจ้งเข้าห้องแอดมิน → แอดมินกด ✅ รับเรื่อง
- บอททำหน้าที่เป็น **สะพาน DM** ส่งข้อความ (และไฟล์แนบ) ไป-กลับระหว่างสองฝ่าย
- ไม่คิดเงิน ไม่ลงบัญชี ไม่ส่งแบบประเมิน
- เงียบเกิน 10 นาที (ปรับได้ที่ `ticket.timeout_minutes`) → ปิดอัตโนมัติ

### 3) VIP Self-Service (3 ระดับ: Lace → Desire → Obsession)
- 💎 เลือกแพ็กเกจ (Lace/Desire เท่านั้น — **Obsession ซื้อเองไม่ได้** ต้องได้จากแอดมินหรือสะสมครบ 12 เดือน) → กรอกโค้ดส่วนลดใน Modal → รับ QR ทาง DM → ส่งสลิป → แอดมินยืนยัน
- ยืนยันแล้วบอท **สลับ Role ให้ตรงกับระดับที่ซื้ออัตโนมัติ** (ถอด Role เก่า/ให้ Role ใหม่) และตั้งวันหมดอายุตาม Life-cycle Logic ด้านล่าง
- 🔍 ตรวจสอบสิทธิ์ VIP ได้เอง — ดูระดับ, วันหมดอายุ, เดือนสะสม, และโควต้าฟรีที่ใช้ไปแล้วในเดือนนี้
- สะสมระดับเดิมครบ 12 เดือน → บอทแจ้งเข้าห้องแอดมินให้อนุมัติอัปเกรดฟรี 1 เดือน (Lace→Desire, Desire→Obsession)
- หมดอายุแล้วบอทถอด Role, รีเซ็ตเดือนสะสม, และแจ้งเตือนลูกค้าอัตโนมัติ (ตรวจทุก ~35 วินาทีในลูปเดียวกับแจ้งเตือนงาน — ถี่กว่า cron รายวันที่เอกสารแนะนำ เพื่อให้ถอดสิทธิ์ได้เร็วขึ้น)

#### Life-cycle Logic (ตาม `VIP logic.txt`)
- **คำนวณวันหมดอายุ**: รายเดือน = บวก 1 เดือนปฏิทิน (31 ม.ค. → 28/29 ก.พ. อัตโนมัติ) · รายปี = บวก 365 วันตรงๆ
- **สะสม/ต่ออายุ**: ต่อระดับเดิมก่อนหมดอายุ → บวกต่อจากวันหมดอายุเดิม · หมดอายุไปแล้วซื้อใหม่ หรือ **เปลี่ยนระดับ (อัปเกรด/ดาวน์เกรด)** → เริ่มนับใหม่จากวันนี้เสมอ (ไม่มีการทบวันที่เหลือของระดับเดิม)
- **เดือนสะสม (สำหรับอัปเกรดฟรี)**: นับต่อเนื่องเฉพาะตอนต่อระดับเดิมก่อนหมดอายุ · **รีเซ็ตเป็น 0 ทันทีที่ปล่อยหมดอายุ หรือเปลี่ยนระดับ**
- **โควต้าฟรีรายเดือน**: รีเซ็ตพร้อมกันทุกคนตามปฏิทินเดือน (ไม่ใช่นับ 30 วันจากวันที่ซื้อ) — คำนวณจากคีย์ `YYYY-MM` ตอนเปิดบิล จึงไม่ต้องมี cron แยกสำหรับรีเซ็ต
- **อัปเกรดฟรีครบ 12 เดือน**: ไม่ทำอัตโนมัติ — บอทแค่แจ้งแอดมินเข้าห้องแอดมินพร้อมปุ่มอนุมัติ/ปฏิเสธเสมอ ตามที่เอกสารระบุ

> **ข้อสมมติที่เพิ่มเข้ามาเอง** (เอกสารต้นฉบับไม่ได้ระบุ ควรตรวจทานก่อนใช้งานจริง): (1) ห้องบริการทั้ง 7 ห้องใช้ร่วมกันได้กับทุกบริการที่ต้องใช้ห้อง ไม่ได้ผูกห้องเฉพาะกับ VIP/VVIP/ระดับใดระดับหนึ่ง (2) การเปลี่ยนระดับ VIP ไม่ว่าอัปเกรดหรือดาวน์เกรดถือเป็น "เริ่มนับใหม่" ทั้งหมด (3) เดือนฟรีที่ได้จากการอนุมัติอัปเกรด 12 เดือน ไม่นับรวมเป็นเดือนสะสมของระดับใหม่ (เริ่มที่ 0)

### 4) รีวิว
- ถึงเวลาจบงาน บอท DM ขอบคุณ + ปุ่ม ✍️ เขียนรีวิว (ใช้ได้ภายใน 24 ชม. และ **1 บิลรีวิวได้ครั้งเดียว**)
- เลือก ⭐ ความประทับใจ และ 🔥 ความแซ่บ แล้วพิมพ์ข้อความใน Modal
- แอดมินอนุมัติ → โพสต์ Embed สีชมพูลงห้องรีวิว (Thumbnail = avatar พนักงาน, ข้อความอยู่ใน code block, Footer = ชื่อลูกค้า)
- ถ้าพนักงานลาออก/ไม่อยู่ในเซิร์ฟเวอร์แล้ว → แสดงเป็น **ชื่อธรรมดา** แทนการ mention

### 5) แจ้งเตือนเวลา + บัญชี
- ลูปทุก ~35 วินาที: เตือนก่อนเริ่มงาน 5 นาที และก่อนจบงาน 5 นาที (ทั้งพนักงานและลูกค้า)
- บิลที่สถานะ `PAID` จะถูกเขียนลง Google Sheets ทันที พร้อมแยก **In / Out / รายได้ร้าน**
- ทุกวันเสาร์ 08:00 น. (เวลาไทย) สร้างแท็บใหม่ `Cycle_YYYY-MM-DD` พร้อมสูตรสรุป และส่งสรุปรอบเก่าเข้าห้องแอดมิน

## เปิดใช้ Google Sheets

1. สร้าง Service Account ที่ Google Cloud → เปิด **Google Sheets API** + **Google Drive API**
2. ดาวน์โหลด JSON key มาวางเป็น `credentials.json` ในโฟลเดอร์นี้
3. **แชร์ Spreadsheet** ให้อีเมลของ Service Account (สิทธิ์ Editor)
4. แก้ `config.json`:

```json
"google_sheets": { "enabled": true, "spreadsheet_id": "ไอดีในลิงก์ชีต", "credentials_file": "credentials.json" }
```

ถ้า `enabled: false` บอทจะทำงานได้ตามปกติทุกอย่าง เพียงแต่ไม่เขียนลงชีต

## ระบบเข้างานพนักงาน

1. สร้าง Role **Staff** และ **On Duty** แล้วลาก Role บอทไว้เหนือทั้งสอง ใส่ ID ใน `roles.staff` / `roles.on_duty`
2. ในห้องสำหรับลงเวลา ใช้ `/panel_attendance` เพื่อโพสต์แผงปุ่ม 🟢 เข้างาน / 🔴 ออกงาน / 🕒 ชั่วโมงของฉัน

| คำสั่ง | ใครใช้ | ทำอะไร |
|---|---|---|
| `/panel_attendance` | แอดมิน | โพสต์แผงลงเวลา (ลบแผงเก่าในห้องให้) |
| `/my_hours` | พนักงาน | ดูชั่วโมงสะสมของรอบปัจจุบัน |
| `/on_duty` | ทุกคน | ดูว่าใครอยู่ในกะตอนนี้ |
| `/attendance_report` | แอดมิน | สรุปชั่วโมงทุกคนในรอบปัจจุบัน |
| `/attendance_fix` | แอดมิน | แก้เวลาเข้า/ออกของกะล่าสุด หรือสร้างกะใหม่ (`new_shift: True`) |

- เข้า/ออกงานทุกครั้งแจ้งในห้องแอดมิน และบันทึกลงชีต `Attendance` เมื่อเปิดใช้ Google Sheets
- ลืมออกงานเกิน `warn_hours` → เตือนทาง DM, เกิน `auto_close_hours` → บอทปิดกะให้ (นับชั่วโมงถึง `warn_hours`) และแจ้งแอดมิน

## เมนูแอดมิน

ใช้ `/panel_admin` ในห้องที่เห็นเฉพาะแอดมิน บอทจะโพสต์แผงปุ่มค้างไว้ ไม่ต้องจำคำสั่ง (คนที่ไม่ใช่แอดมินกดแล้วใช้ไม่ได้)

| ปุ่ม | ทำอะไร |
|---|---|
| 📊 สรุปยอดรอบนี้ | เหมือน `/summary` |
| 🕒 ชั่วโมงงาน | เหมือน `/attendance_report` |
| 🟢 ใครอยู่ในกะ | เหมือน `/on_duty` |
| 💎 ให้สิทธิ์ VIP | เลือกสมาชิก → ระดับ → จำนวนเดือน แทน `/vip_grant` |
| ✏️ แก้เวลาเข้างาน | เลือกพนักงาน แล้วกรอกเวลาในฟอร์ม แทน `/attendance_fix` |
| ✂️ ตัดรอบทันที | มีปุ่มยืนยันกันกดพลาด |
| 🩺 สถานะระบบ / 🔄 โหลด config ใหม่ / 📖 คำสั่งทั้งหมด | ตรวจการตั้งค่า, โหลด `config.json` ใหม่, ดูรายการคำสั่ง |
